# PolyForge — 335 modelos no mesmo arquivo

**[Baixar o ZIP atualizado](https://raw.githubusercontent.com/opatrecio-droid/Chatgpt/polyforge-download-2026-10-22/polyforge.zip)** · [Baixar apenas o HTML](https://raw.githubusercontent.com/opatrecio-droid/Chatgpt/polyforge-download-2026-10-22/polyforge.html)

Extraia o ZIP e abra **polyforge.html** no Chrome ou Edge atualizado.

Esta é uma coleção cumulativa: os 35 modelos iniciais são mantidos e cada atualização acrescenta 10. Todos estão incluídos no mesmo HTML. Na coleção maior, o modelo selecionado é carregado quando necessário para reduzir o uso inicial de memória.

A biblioteca inclui animais, personagens, natureza, veículos, objetos, construções e peças modulares. Há variantes geométricas de algumas famílias. Cópias de geometria e mudanças apenas de cor não contam como modelos novos. Os GLBs são de Kenney e Quaternius, CC0, com fontes e nomes originais registrados.

Confira [o catálogo](polyforge-catalogo.json), [a validação da atualização](polyforge-validacao.json) e [o histórico cumulativo](ATUALIZACOES.md).
